# Sources des données

La [liste des sources et des licences](../../donnees.md) présente les producteurs, les liens vers les jeux, les fichiers locaux et les méthodes de récupération.

Le [catalogue des fichiers](catalogue_fichiers.md) décrit les colonnes, les traitements connus et les limites des données.

`datasets/clean/shared/` contient des données préparées communes aux scripts : le GeoPackage des communes et de l’emploi, les groupes de communes desservies par ligne et les séries régionales et par groupe de l’Urssaf et de la Dares. Ces fichiers sont des entrées pour plusieurs planches ; leur préparation initiale n’est pas entièrement reproductible avec les scripts disponibles.

Le [catalogue des données web](../web/docs/donnees.md) décrit les trois instantanés utilisés par le site, leurs entrées locales et les scripts de préparation. Les commandes et les limites de reproduction figurent dans les [instructions d'exécution](execution.md).
